The gap

The hardest part of prompting
is the model?the prompt?the tokens?the instructions?the context window?remembering.

A session ends and takes everything with it. Next week the same repo gets explained again, and the same reasoning derived from scratch.

What we ask for, constantly
"Open the session from two weeks back."
"Which session touched payments.py?"
"Which prompt made it do that?"
"Did a key ever land in a transcript?"

Today every one of them ends the same way — scroll back and hope.

And it is not free
Tokens burnedthe same context re-sent every session. You pay to explain the repo again, and again.
Work redonecompaction drops an hour of reasoning mid-task, and it gets re-derived from scratch.
Security gapkeys sitting in transcripts nobody has read, from runs nobody watched.

Copilot ships --continue, --resume, a sessions tab and /chronicle — the last of those the most useful by some way. But that is the entire toolkit, and it profiles a bounded window of recent sessions.

The solution

Now it remembers.

Copilot Sessions (cs)
A terminal browser over the store you already have.

$ cs
Find

Every session, searchable

cs search cs read cs resume

Measure

Every credit, counted

cs cost cs stats cs agents

Secure

Every key, caught

cs audit cs yolo cs handoff

Reference

Every tool, accounted

cs skills cs hooks cs mcp

cs — the landing screen. Every view one keypress away.
